# omdubey.com

Om Dubey's personal site. Plain static HTML, CSS and JS, no build step.

- Hosting: Vercel (static). `vercel.json` sets caching and headers.
- The page reads everything from `js/content.js`.
- `llms.txt` and `om-dubey.md` are the same content for AI tools.
- The old site lives on the `legacy-site` branch.
